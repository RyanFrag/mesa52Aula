Ícone, localização e Google no celular

PDM II · Cada passo abre um arquivo, mostra a linha que já está lá e diz o que muda. O APK entra só no final.

1

Olhar as permissões e acrescentar as duas de GPS

android/app/src/main/AndroidManifest.xml

Abra o manifesto. Desça até o comentário Permissions, depois de </application>.

Você vê

<uses-permission android:name="android.permission.INTERNET" />

O plugin de geolocalização não declara permissão no manifesto dele. Sem as duas linhas abaixo, o APK responde OS-PLUG-GLOC-0018 e a tela mostra que falta permissão no manifesto.

Mude

Cole estas duas linhas logo abaixo da de INTERNET. Salve. Se ACCESS_FINE_LOCATION já estiver aí, não cole de novo.

<uses-permission android:name="android.permission.INTERNET" />
<uses-permission android:name="android.permission.ACCESS_COARSE_LOCATION" />
<uses-permission android:name="android.permission.ACCESS_FINE_LOCATION" />

COARSE é a localização aproximada. FINE é a precisa, a do enableHighAccuracy: true que já está em lerPosicao. Não cole permissão de armazenamento. A foto desta aula não vai para a galeria.

Fale isto para a turma

O celular não usa o desenho grande que a IA fez. Ele precisa de várias cópias: o ícone da gaveta, o redondo, a tela que pisca ao abrir, e o mesmo desenho em tamanhos diferentes. No projeto de vocês o comando é o mesmo. Muda o desenho e, se quiserem, a cor. A pasta android precisa existir e o arquivo precisa se chamar assets/logo.png.

--android porque não existe pasta ios. #1e293b é o fundo do ícone da gaveta. #f8fafc é o fundo da splash clara. 0.4 deixa o símbolo visível. O padrão 0.2 deixa um pontinho. Não copie arquivo na mão para dentro de mipmap. O comando grava mdpi, hdpi, xhdpi, xxhdpi e xxxhdpi.

8

Acrescentar o retorno do Google no Capacitor

capacitor.config.ts

Volte no arquivo do passo 3. O appName já é Mesa 52. O objeto ainda não tem server nem overrideUserAgent.

Sem allowNavigation, o Capacitor joga a página do Google no Chrome, e o Chrome tenta voltar para https://localhost, que não reabre o app. O overrideUserAgent tira a marca wv. Com ela, o Google recusa o login dentro do app.

Deixe o arquivo assim

Substitua o conteúdo. appId continua o mesmo.

import type { CapacitorConfig } from '@capacitor/cli';

const config: CapacitorConfig = {
  appId: 'io.ionic.starter',
  appName: 'Mesa 52',
  webDir: 'www',
  overrideUserAgent:
    'Mozilla/5.0 (Linux; Android 14; Mobile) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/131.0.6778.135 Mobile Safari/537.36',
  server: {
    allowNavigation: [
      '*.google.com',
      '*.google.com.br',
      '*.youtube.com',
      '*.googleapis.com',
      '*.gstatic.com',
      '*.googleusercontent.com',
      '*.firebaseapp.com',
      '*.web.app',
    ],
  },
};

export default config;

Olhar o getAuth e trocar a criação do auth

src/app/firebase.config.ts

Abra o arquivo. O objeto firebaseConfig fica inteiro, com a apiKey de vocês.

Você vê, no topo

import { initializeApp } from "firebase/app";
import { getAuth } from "firebase/auth"
import { getFirestore } from "firebase/firestore"

Você vê, no final

const app = initializeApp(firebaseConfig);
export const auth = getAuth(app);
export const db = getFirestore(app);

Mude os imports e a linha do auth

No celular o localStorage some quando o app fecha. O IndexedDB segura o login enquanto a página do Google está aberta. No navegador continua o getAuth.

import { Capacitor } from "@capacitor/core";
import { initializeApp } from "firebase/app";
import { getAuth, indexedDBLocalPersistence, initializeAuth } from "firebase/auth"
import { getFirestore } from "firebase/firestore"
const app = initializeApp(firebaseConfig);
export const auth = Capacitor.isNativePlatform()
  ? initializeAuth(app, { persistence: indexedDBLocalPersistence })
  : getAuth(app);
export const db = getFirestore(app);

initializeAuth só pode ser chamado uma vez. Não deixe um export const auth = getAuth(app) antigo embaixo do novo.

11

Olhar o AppComponent e colocar o retorno

src/app/app.component.ts

Quando a pessoa escolhe a conta, o app recarrega. O botão da tela de login não está mais na memória. Quem manda para a Home é este arquivo.

Você vê

import { Component } from '@angular/core';
import { IonApp, IonRouterOutlet } from '@ionic/angular/standalone';

export class AppComponent {
  constructor() {}
}

A classe não implementa OnInit e o construtor está vazio.

Deixe o arquivo assim

import { Component, OnInit } from '@angular/core';
import { Router } from '@angular/router';
import { Capacitor } from '@capacitor/core';
import { getRedirectResult } from 'firebase/auth';
import { IonApp, IonRouterOutlet } from '@ionic/angular/standalone';
import { auth } from './firebase.config';

@Component({
  selector: 'app-root',
  templateUrl: 'app.component.html',
  imports: [IonApp, IonRouterOutlet],
})
export class AppComponent implements OnInit {
  constructor(private router: Router) {}

  ngOnInit() {
    if (!Capacitor.isNativePlatform()) {
      return;
    }
    getRedirectResult(auth).then((resultado) => {
      if (resultado?.user) {
        this.router.navigateByUrl('/home');
      }
    });
  }
}

Se o arquivo de vocês se chama firebase.ts, o import é ./firebase. O HTML deste arquivo muda no passo 12, quando entra o menu.

Atividade

Cada aluno repete no próprio app, o da API pública. Um APK só no final. Onde o guia diz Mesa 52, use o nome do app de vocês.

1
Olhar o GPS que já existe

No seu home ou na página logada, ache getCurrentPosition. Se não existir, escreva uma leitura só, mostre latitude e longitude e um botão para o OpenStreetMap.

2
Manifesto

Abra o AndroidManifest.xml, ache INTERNET e coloque ACCESS_COARSE_LOCATION e ACCESS_FINE_LOCATION embaixo.

3
Nome e desenho

Troque appName e as duas strings do strings.xml. Salve o PNG da IA em icones/icone-app.png, copie para assets/logo.png e rode o generate --android. Abra o ic_launcher.png e compare com o icone-gaveta.png antes do APK.

4
Firebase

Google ativado e localhost nos domínios. Sem google-services.json.

5
Login no APK

No service, o return do Google vira redirect no celular e popup no navegador. No componente raiz, getRedirectResult vai para a rota logada de vocês.

6
Menu lateral

Um ion-menu com duas linhas no nome do app de vocês. O botão de três risquinhos fica na página logada. contentId igual ao id do ion-router-outlet.

7
Um APK

npm run build, npx cap sync android, instalar. Ícone novo, localização com permissão, Google dentro do app.

+
Desafio

Troque só o --splashBackgroundColor para uma segunda cor, gere de novo e mostre a splash diferente do fundo do ícone.
